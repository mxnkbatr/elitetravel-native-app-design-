# UX шалгалт: хэрэглэгчийн туршилт ба iPhone

## 1. Хэрэглэгчийн туршилт (3–5 хүн, нэг хүнд ~15 мин)

**Хэнийг:** манай жинхэнэ үйлчлүүлэгч шиг хүмүүс. Аялалд явж үзсэн, утсаараа захиалга хийдэг 25–45 настай хүмүүс. Баг болон гэр бүлийнхнээ оролцуулахгүй.

**Яаж:** хүний гарт утсыг нь өгөөд, дэлгэцийг нь бичлэгт оруул (iPhone дээр Screen Recording). Хэрэглэгч бодож байгаагаа чангаар хэлж явна. Чи **юу ч зааж, тусалж болохгүй.** Гацвал "Чи одоо юу хайж байна?" гэж л асуу.

**Даалгаврууд (нэг нэгээр нь өг):**

1. "Есдүгээр сард Хайнань руу 2 том хүн, 1 хүүхэдтэй явах аяллыг ол. Нийт хэд болохыг хэл."
2. "Тэр аялалд захиалгын хүсэлт илгээ." (Туршилтын нэр, утас ашиглуулаад, илгээсний дараа admin-аас устга.)
3. "Илгээсэн захиалгаа буцаагаад ол."
4. "Бали аялалд юу багтдаг, юу багтдаггүйг хэл."
5. "Асуух зүйл гарвал хэнтэй, яаж холбогдох вэ?"

**Тэмдэглэх зүйлс:**

| Даалгавар | Амжилттай? | Хугацаа | Хаана гацсан / юу хэлсэн |
|---|---|---|---|
| 1 | | | |

| 5 | | | |

**Дараа нь асуух:** "Хамгийн их бухимдуулсан зүйл юу байсан бэ?" болон "Нэг юм өөрчилж болдог бол юуг өөрчлөх вэ?"

5 хүнээс 2 ба түүнээс олон нь нэг газар гацсан бол тэр нь жинхэнэ асуудал. Түүнийг эхэлж засна.

## 2. iPhone дээр нухацтай гүйлгэж үзэх

Сайтыг Safari дээр, аппыг TestFlight эсвэл App Store-оос нээж, хоёуланд нь шалгана.

- [ ] Анх нээхэд цагаан дэлгэц анивчихгүй, нүүр хуудас 2 секундэд харагдана.
- [ ] Аялал руу ороход хуудас баруунаас гулсаж орж ирнэ. Зүүн захаас swipe хийх эсвэл буцах товч дарахад буцаж гулсаж гарна.
- [ ] Цэс хооронд (Аялал, Газрын зураг, Мэдээ, Захиалга) шилжихэд анивчихгүй.
- [ ] Чат товч dock-ийн дээр, гарын хуруунд хүрэхээр байрлалд байна. Нээхэд товчноосоо тойрог хэлбэрээр дэлгэгдэнэ. Гар (keyboard) гарч ирэхэд бичих хэсэг далдлагдахгүй.
- [ ] Захиалга: 3 алхам → утасны дугаар бичихэд тоон гар гарна → илгээхэд boarding pass гарна.
- [ ] Дээрээс доош татахад (pull-to-refresh) Захиалга хуудас шинэчлэгдэнэ.
- [ ] Notch болон доод зураасны (home indicator) хэсэгт товч, текст далдлагдахгүй.
- [ ] Профайл цэсний өнгөний горимоос "Бараан"-ыг сонгоход бүх хуудас уншигдахуйц байна.
- [ ] Интернэтээ унтраахад "Интернэт тасарлаа" мэдэгдэл гарна. Асаахад алга болно.
- [ ] Settings → Accessibility → Text Size-ийг томруулахад текст давхцахгүй.
- [ ] VoiceOver асаагаад нүүр хуудсаар явахад товч бүр нэртэй уншигдана.

Асуудал олдвол дэлгэцийн зураг авч, хаана юу болсныг нэг өгүүлбэрээр бичээд илгээ.

## 3. Хэмжилт (admin → Тайлан → "Захиалгын зам")

Сайт → аялал үзсэн → маягт нээсэн → **нэр, утсаа бөглөх хэсэгт хүрсэн** → илгээсэн → төлбөр эхлүүлсэн. Алхам бүрийн хооронд хэдэн хувь нь гарсныг харуулна. Хамгийн их уналттай алхам улаанаар тодорно. 1–2 долоо хоногийн дараа тэр алхмыг эхэлж засна.
